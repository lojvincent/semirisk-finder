# Semiconductor Component Origin and Risk Finder

A class MVP (minimum viable product). It is not production software.

## 1. What this MVP tests

It tests one research question:

> When semiconductor equipment subsystem suppliers need to respond to a customer-origin request or assess a country dependency, does a centralized supply-chain intelligence tool help them locate and communicate the relevant supplier information faster and more accurately than fragmented spreadsheets?

One tester answers three sourcing questions using **fragmented records**: three separate tabs that act like separate spreadsheets and documents. Then they answer three more questions using a **centralized dashboard** with search, filters, a supplier-chain view, and a customer-response generator. The app times both exercises, scores the answers, and compares the two methods.

## 2. How to open and use it

You do not need to install anything or use an internet connection.

1. **Find the file.** Locate `index.html` in the same folder as this README.
2. **Open it.** Double-click `index.html`. It opens in your web browser (Chrome, Edge, Safari, or Firefox).
3. **Do the Current Process Test.** Read the Instructions, then click **Begin Current Process Test**. A timer starts. Switch between tabs A, B, and C and match Component IDs to answer the three questions. Then click **Submit Current Process Answers**.
4. **Do the Centralized Tool Test.** Click **Begin Centralized Tool Test**. A second timer starts. Use the search box, filters, and table to answer three new questions. You can click any row to see its supplier chain, click **Generate Customer Response**, and then click **Copy Response**. When you are done, click **Submit Centralized Tool Answers**.
5. **Review the Results.** The Results page shows both times, both scores, the time difference, the percentage change, and the correct answers.

Tips:
- Each timer keeps running if you switch sections, so stay on a test until you submit it.
- Results are kept only in the open browser tab. Closing or refreshing the page clears them.
- If your browser blocks the Copy Response button, the app selects the text for you. Press **Ctrl+C** (Windows) or **Cmd+C** (Mac) to copy it.

## 3. How to reset the experiment

On the Results page, click **Reset Experiment**. This clears both timers, all answers and scores, the search box and filters, any generated response, and the stored results. Then it returns you to the Instructions.

Refreshing the browser page also starts everything over.

## 4. All data is fictional

Every company, component, supplier, country link, date, and risk note in this app is made up for class testing. Risk labels are illustrative and are not legal or compliance advice.

## 5. What this prototype does and does not test

This prototype tests **information retrieval and communication**: how quickly and accurately someone can find supplier-origin facts and turn them into a customer response.

It does **not** collect real supplier data, connect to ERP systems or documents, or independently verify where any component comes from. It is a small directional class test. Its results should not be read as evidence about all supply-chain professionals.
