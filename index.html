Class MVP · Supplier-origin retrieval experiment

Semiconductor Component Origin and Risk Finder

Notice: Fictional data for class testing only. Risk labels are illustrative and are not legal or compliance advice.

Instructions

You will complete two short sourcing exercises using the same fictional semiconductor supply-chain records. First, you will use fragmented records that simulate separate spreadsheets and documents. Second, you will use a centralized search and risk dashboard. Your completion time and answer accuracy will be compared.

How it works

  1. Click Begin Current Process Test. A timer starts right away.
  2. Answer three questions by switching between three separate record tabs and matching Component IDs. Pick one Component ID per question, then click Submit Current Process Answers.
  3. Click Begin Centralized Tool Test. A second timer starts. Answer three different questions using the dashboard's search, filters, and table, then click Submit Centralized Tool Answers.
  4. Review both completion times and scores in Results. Correct answers are shown only there.

Before you start

  • This is a small directional class experiment. Results may be affected by the tester becoming familiar with the data, because the Centralized Tool Test always comes second.
  • Each question has exactly one correct Component ID.
  • A timer keeps running if you switch to another section, so stay on the test until you submit.
  • Results are kept only in this browser tab. Refreshing or closing the page clears them.
